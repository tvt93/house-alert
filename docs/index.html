Dagelijkse mail instellen

Elke ochtend één mail met de nieuwe woningen die door de filters hieronder komen. De instelling is een klein bestand in de repository; GitHub opent het al ingevuld, jij klikt enkel op Commit.

$MAIL_TO leest het adres uit de GitHub-secret met die naam, zodat je adres niet in de publieke repo staat. $MAIL_TO_PARTNER, $MAIL_TO_2 en $MAIL_TO_3 werken ook zodra je zo'n secret aanmaakt onder Settings → Secrets. Een letterlijk e-mailadres mag, maar is dan publiek zichtbaar.
